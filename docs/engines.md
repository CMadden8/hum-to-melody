# Audio engines and credits

- **pYIN** extracts note events from monophonic audio. Matthias Mauch and Queen Mary University of London developed the plugin, using YIN code from Joren Six’s TarsosDSP. Setup verifies the [official Vamp Plugin Pack 2.0](https://github.com/vamp-plugins/vamp-plugin-pack/releases/tag/v2.0) and extracts its unchanged x64 DLL. See the [authors’ notes](../licenses/pYIN-README.txt) and [GPL licence](../licenses/pYIN-COPYING.txt).
- **FluidSynth** renders MIDI with sampled instruments. Setup fetches the official [FluidSynth 2.4.6 Windows distribution](https://github.com/FluidSynth/fluidsynth/releases/tag/v2.4.6). Its [source and licence](https://github.com/FluidSynth/fluidsynth/blob/v2.4.6/COPYING) are maintained upstream.
- **MuseScore General** supplies the instrument sounds. The [SoundFont distribution](https://ftp-osl.osuosl.org/pub/musescore/soundfont/MuseScore_General/) is downloaded separately. The [licence and credits](../licenses/MuseScore_General_License.md) and [sample source inventory](../licenses/MuseScore_General_Sample_Sources.csv) are included.
- MIDI writing uses Mido. NumPy handles signal buffers, SoundFile/libsndfile read and write audio, sounddevice/PortAudio handle microphone and speaker I/O, and Qt for Python supplies the UI. [Pinned Python dependencies](../requirements.lock.txt) retain their notices when installed.
